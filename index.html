01 Patois Labs

What I build for work: open tools for translation.

Localization OS

An open source, self-hosted translation management system that starts from machine translation. Translation memory, glossaries, automated quality checks and workflows you describe in a sentence, on your own server.

OpenCode

ChatterCAT

A translator's editor you can talk to. Dictate a translation, or say a command to pull in a translation memory match or machine translation, and keep your hands off the mouse.

Open

Bilingua

File parsers for translation, in Rust. Open a Word document, a PO catalog, a subtitle file or an XLIFF, get its translatable text with the formatting kept, and write the translation back into the same file.

Code

Mallard

Local-first meeting notes for Windows. It records your mic and the call as two tracks while you type timestamped notes, then your own server transcribes it and writes the summary and action items.

Read

Everything is saved as Markdown you own, searchable by person, company and date. The transcription runs on the same home server as everything else on this page, so no call audio leaves the house.

02 Built with AI

Things I built with Claude, mostly for my own house.

Home Lab

"Alexa, open home lab." Claude answers through my Echo, files to-dos and notes in my project tracker, reads out what's due, changes items and undoes them. Say "systems check" and it checks every service I run in under a second.

Read

A private Alexa skill points at a small service on my home server. Claude runs a short tool loop against the tracker's API, and Alexa gets an answer in about two seconds, well inside its eight-second limit. Anything that touches more than one thing waits for a spoken "yes", and that rule lives in code, not in the prompt. Every change is logged with its undo, so "undo that" works even the next day.

The systems check skips Claude entirely: it probes the company sites, the apps and the home server in parallel, and the answer it wants to give is "All systems are online and green."

The Strix Halo

My home AI server: a small box built on AMD's Strix Halo chip, with 128 GB of memory and an RTX 3090 hanging off it by cable. It runs my translation models, an embeddings server, a voice server, the project tracker and everything else here.

Read

The Localization OS translations in production come from open-weights models on this box, not from a cloud AI service. It also runs speech recognition and text to speech for ChatterCAT, the transcription for Mallard, and a live log of every model call. A daily job drains swap, and a health check pushes to my phone when a disk fills or a service fails.

Kindle dashboard

A jailbroken Kindle Paperwhite on my desk shows whether my sites are up, what I've spent on AI this month and how the home server is doing, redrawn every five minutes.

Read

The server draws the page as an image from its monitoring data and the spend reports of each AI provider. The Kindle pauses its own interface, fetches the image and sleeps between refreshes when it's on battery. Tap the screen three times to get the Kindle back.

Coder comparison

The same bug goes to three coding agents at once: a local Qwen model on my server, and two cloud agents, each in its own copy of the repo. Claude Opus then reviews each attempt and writes up the good and the bad.

Read

Nothing gets merged; it's an evaluation. It answers a practical question: which work can a model running in my house do as well as the cloud ones, and where does it still fall short.

03 Building AI

Experiments on models: training them, editing them and testing them, mostly on the Strix Halo.

Read-ahead translation

Does reading the whole document first fix early translation guesses? A 60-segment guide with six traps the document only explains later, like a job title that must be feminine or a currency named near the end, into German and Japanese on six models.

Traps translated right before the document explains them: a running conversation, then with the source read first.

Claude Sonnet
41% → 93%
Gemini
15% → 74%
Qwen 27B, local
9% → 64%
Claude Haiku + a check pass
50% → 100%
Read

A running conversation locks in its first guess and repeats it consistently, which only helps when the guess was right; only Opus got by on the conversation alone. Reading the source first was the most reliable fix, for 0 to 5% more cost. A final check pass suited strong instruction followers. Best value: Sonnet with read-ahead at 93% for about four cents per language, or Haiku with the check pass at 100% for under a cent. A small test: one document, two runs each.

Distilling Gemma 26B into 12B

Overnight on the Strix Halo: Gemma 4 26B translated 23,500 sentences into five languages, a quality filter kept 17,794, and a LoRA taught Gemma 4 12B to translate like its teacher. 3.3 hours of training on one RTX 3090.

Real gains where it mattered for translation work, flat on the classic metric, and still behind the teacher (3.4% major errors). The cost was speed: 57 instead of 79 segments a minute while the adapter is applied at run time. The 26B stays the better choice when the GPU can hold it; the distilled 12B is for when it can't, or for one small adapter per customer.

Weight-space programming

Editing a model's weights directly, with no training. I reproduced MIT's "Sparks of Weight-Space Programming" on my own hardware, then tried the method on my own translation model.

MATH-500, Qwen 3.5 0.8B
6% → 44%
Weights changed
0.015%
Tags kept, Hy-MT2 1.8B
55% → 61%
Read

Step one: the paper's edit touches two tensors and is exactly rank one; the model writes a little less along one direction. On the Strix Halo it went from 6% to 44% on the same 50 problems, matching the published 44%. It got 19 right that the base model missed and lost none.

Step two: Claude Opus looked inside a 1.8B translation model, found two attention heads that write inline tags, and doubled them. Segments with every tag intact went from 55.3% to 60.8%. A real, specific effect (a random edit of the same size did nothing), but too small to ship.

First fine-tune

QLoRA on a 9B model with real translation memory, on one RTX 3090. It improved in-domain English to Spanish by 2.8 BLEU, and also started answering in Spanish when asked for French.

Train every language pair together.

Semantic translation memory

Translation memory search by meaning instead of by matching characters, with a multilingual embeddings model on the home server, added to Localization OS.

Model archive

Archives Hugging Face model repos to cold storage one file at a time: download, check the hash, upload, delete. A 100 GB model never needs 100 GB of free disk.
